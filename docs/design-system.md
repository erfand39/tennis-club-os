# سیستم طراحی و نمونهٔ تعاملی

## هویت بصری

خطوط زمین، نشان باشگاه و تصویر نمای امروز را شکل می‌دهند. پالت سبز جنگلی و لیمویی، با زمینهٔ گرم و سطوح سفید، برای نمایش زمان و وضعیت فضای کافی می‌دهد. «رزرو سانس» عمل اصلی است. «مشاهدهٔ تقویم» و عملیات ردیف در سطح بصری دوم قرار می‌گیرند.

| ویژگی | مقدار یا قاعده |
| --- | --- |
| زمینه و سطح | `#F7F8F3` برای بوم و `#FFFFFF` برای پنل |
| متن | `#202923` برای متن اصلی و `#52635A` برای متن کمکی |
| رنگ اصلی | `#174C3C` جنگلی، `#10382E` سبز تیره و `#D5EAA7` لیمویی برای عمل اصلی |
| خط و حالت فوکوس | `#E2E8DF` برای جداکننده. `#327250` با ضخامت ۳ پیکسل برای فوکوس |
| تایپوگرافی | Vazirmatn متغیر با وزن ۱۰۰ تا ۹۰۰. سرفصل صفحهٔ دسکتاپ ۲۷ تا ۳۷ پیکسل. ساعت و عدد آماری با ارقام هم‌عرض. ساعت در متن راست‌به‌چپ در بلوک مستقل چپ‌به‌راست قرار می‌گیرد. |
| فاصله و شعاع | فاصلهٔ اجزای نزدیک ۶ تا ۱۰، پنل‌ها ۱۲ تا ۲۰ و حاشیهٔ دسکتاپ ۲۰ تا ۴۵ پیکسل. شعاع پنل ۱۷ و کنترل ۹ تا ۱۲ پیکسل. |
| حالت و عمق | حاشیهٔ ظریف و سایهٔ کم‌دامنه روی پنل. لایهٔ اعلان بالای ناوبری موبایل. فرم مودال با لایهٔ بومی مرورگر. |
| حرکت | ۱۵۰ میلی‌ثانیه برای تغییر حالت کنترل و ۱۶۰ میلی‌ثانیه برای ورود فرم و اعلان. احترام به `prefers-reduced-motion`. |
| واکنش‌گرایی | در ۸۸۰ پیکسل و کمتر ناوبری پایین جای سایدبار را می‌گیرد. در ۶۲۰ پیکسل و کمتر تقویم روزانه به فهرست زمانی و فرم به پنل پایین تبدیل می‌شود. |

## اجزا و رفتار

| جزء | رفتار نمونه |
| --- | --- |
| سربرگ، سایدبار و ناوبری پایین | نمایش شعبه، مسیر فعال، پیوند محتوای اصلی، و راهنمای دادهٔ آزمایشی |
| داشبورد | سانس بعدی، سانس‌های پیش رو، اشغال، زمین‌های فعال و تعداد جلسات آموزشی |
| تقویم | جابه‌جایی تاریخ شمسی در نمای روز، هفته و ماه، فیلتر زمین، فهرست روزانهٔ موبایل و ورود از بازهٔ آزاد در نمای شبکه‌ای |
| فرم و جزئیات رزرو | اجاره یا آموزش، انتخاب تاریخ و زمان، تعرفهٔ نمونه، ویرایش، لغو با تأیید، خطای تداخل با حفظ فیلدها |
| فهرست زمین‌ها | کارت زمین، نوع سطح، وضعیت و ورود به تقویم همان زمین |
| فهرست افراد | تب مربیان و شاگردان، جست‌وجوی نام، وضعیت فعال و غیرفعال و نتیجهٔ خالی |
| وضعیت‌ها | بارگذاری اولیه، فهرست خالی، خطای قابل اصلاح، پیام ثبت موفق و نشانهٔ لغو با متن |
| دسترس‌پذیری | دکمه و فرم بومی، برچسب متنی وضعیت، نشانگر فوکوس، بستن فرم با Escape و بازگشت فوکوس به کنترل شروع |

## الگوی صفحات در ادامهٔ نقشهٔ راه

| صفحه | طرح عملیاتی |
| --- | --- |
| ورود و بازیابی | فرم تک‌ستونه، خطای نزدیک فیلد، وضعیت ارسال و پیام بازگشت به ورود |
| جزئیات زمین | مشخصات و وضعیت در بالا، ساعات کاری، تعمیرات و تقویم همان زمین |
| مربی و شاگرد | فهرست جست‌وجوپذیر، جزئیات با تب سوابق، برنامه و وضعیت |
| کلاس و حضور | فهرست جلسه‌ها، ظرفیت، فهرست حضور لمسی و تأیید پایان جلسه |
| مالی | فهرست فاکتورها و مانده، جزئیات دریافت و بازپرداخت با واحد صریح |
| گزارش‌ها | فیلتر بازه و شعبه، شاخص‌های قابل ردیابی، جدول ریز و خروجی |
| تنظیمات و کاربران | گروه‌های شعبه، ساعات، تعرفه و دسترسی. فرم مجوز با نمایش محدودهٔ شعبه. |
| اعلان‌ها | فهرست گروه‌بندی‌شده بر اساس تاریخ، خوانده‌شده و اقدام مربوط به رخداد |

صفحات عملیاتی جدول آخر هنگام پیاده‌سازی ماژول‌های مربوط فعال می‌شوند. فاز ۰۱ برای بازبینی زبان بصری، فرم، تقویم و حرکت بین صفحات اصلی طراحی شده است.

## اجرا و بررسی

```sh
node --test scripts/preview.test.mjs
node scripts/build-preview.mjs
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

| بررسی انجام‌شده | نتیجه |
| --- | --- |
| قواعد رزرو و تاریخ شمسی | ۷ آزمون Node موفق. تداخل مستقل زمین، مربی و شاگرد، زمان مجاور، خروج از ساعات کار، رزرو لغوشده، دادهٔ ذخیره‌شده و مرز ماه شمسی |
| مرورگر دسکتاپ | ثبت آزمایشی، رد تداخل و حفظ نام، تغییر شاخص و سانس بعدی، ویرایش به بازهٔ مجاور، ماندگاری پس از بارگذاری مجدد، لغو و بازگشت شاخص، فیلتر زمین و جابه‌جایی نمای روز، هفته و ماه |
| مرورگر در اندازه‌های واکنش‌گرا | عرض‌های ۳۲۰، ۳۹۰، ۷۶۸، ۱۰۲۴ و ۱۹۲۰ پیکسل بدون اسکرول افقی صفحه. تقویم ماهانه و فرم در عرض ۳۹۰، جست‌وجو و حالت خالی در عرض ۳۲۰. |
| صفحه‌کلید | بستن فرم با Escape و بازگشت فوکوس به «رزرو سانس» در مرورگر بررسی شد. |
| باقی‌مانده برای نسخهٔ عملیاتی | آزمون روی دستگاه واقعی iPhone و Android، ارزیابی عملکرد با دادهٔ عملیاتی، نقش‌ها، تراکنش و قیدهای پایگاه داده |

نمونه از داده‌های ساختگی ۲۰ آبان ۱۴۰۵ و ذخیرهٔ همان مرورگر استفاده می‌کند. عملیات واقعی رزرو، پرداخت، ورود و همگام‌سازی بین دستگاه‌ها به فازهای بعدی وابسته‌اند. تصویر زمین برای همین نمونه تولید شده است. فونت Vazirmatn از بستهٔ Fontsource نسخهٔ ۵٫۳٫۰ همراه با مجوز OFL در سورس قرار دارد.
