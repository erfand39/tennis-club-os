# سیستم طراحی باشگاه تنیس سام

## هویت بصری

خطوط زمین، نشان باشگاه و تصویر نمای امروز را شکل می‌دهند. پالت سبز جنگلی و لیمویی، با زمینهٔ گرم و سطوح سفید، برای نمایش زمان و وضعیت فضای کافی می‌دهد. «رزرو سانس» عمل اصلی است. «مشاهدهٔ تقویم» و عملیات ردیف در سطح بصری دوم قرار می‌گیرند.

| ویژگی | مقدار یا قاعده |
| --- | --- |
| زمینه و سطح | `#F7F8F3` برای بوم و `#FFFFFF` برای پنل |
| متن | `#202923` برای متن اصلی و `#52635A` برای متن کمکی |
| رنگ اصلی | `#174C3C` جنگلی، `#10382E` سبز تیره و `#D5EAA7` لیمویی برای عمل اصلی |
| خط و حالت فوکوس | `#E2E8DF` برای جداکننده. `#327250` با ضخامت ۳ پیکسل برای فوکوس |
| تایپوگرافی | Vazirmatn متغیر با وزن ۱۰۰ تا ۹۰۰. سرفصل صفحهٔ دسکتاپ ۲۷ تا ۳۷ پیکسل. ساعت و عدد آماری با ارقام هم‌عرض. ساعت در متن راست‌به‌چپ در بلوک مستقل چپ‌به‌راست قرار می‌گیرد. |
| فاصله و شعاع | فاصلهٔ اجزای نزدیک ۶ تا ۱۰، پنل‌ها ۱۲ تا ۲۰ و حاشیهٔ دسکتاپ ۲۰ تا ۴۵ پیکسل. شعاع پنل ۱۷ و کنترل ۹ تا ۱۲ پیکسل. |
| حالت و عمق | حاشیهٔ ظریف و سایهٔ کم‌دامنه روی پنل. اعلان وضعیت اتصال در بالای صفحه. |
| حرکت | ۱۵۰ میلی‌ثانیه برای تغییر حالت کنترل و احترام به `prefers-reduced-motion`. |
| واکنش‌گرایی | تا عرض ۸۴۰ پیکسل منوی مدیر به‌صورت شبکه‌ای بالای محتوا قرار می‌گیرد. در عرض‌های بیشتر منو در سمت راست است. |

## اجزا و رفتار

| جزء | رفتار رابط |
| --- | --- |
| سربرگ و منوی مدیر | نمایش شعبه، بخش فعال و همهٔ بخش‌های مجاز مدیر |
| داشبورد | سانس بعدی، سانس‌های پیش رو، اشغال، زمین‌های فعال و تعداد جلسات آموزشی |
| تقویم | جابه‌جایی تاریخ شمسی در نمای روز، هفته و ماه، فیلتر زمین، فهرست روزانهٔ موبایل و ورود از بازهٔ آزاد در نمای شبکه‌ای |
| فرم و جزئیات رزرو | اجاره یا آموزش، انتخاب تاریخ و زمان، تعرفهٔ ثبت‌شده، ویرایش، لغو با تأیید، خطای تداخل با حفظ فیلدها |
| فهرست زمین‌ها | کارت زمین، نوع سطح، وضعیت و ورود به تقویم همان زمین |
| فهرست افراد | تب مربیان و شاگردان، جست‌وجوی نام، وضعیت فعال و غیرفعال و نتیجهٔ خالی |
| وضعیت‌ها | بارگذاری اولیه، فهرست خالی، خطای قابل اصلاح، پیام ثبت موفق و نشانهٔ لغو با متن |
| دسترس‌پذیری | دکمه و فرم بومی، برچسب متنی وضعیت، نشانگر فوکوس، بستن فرم با Escape و بازگشت فوکوس به کنترل شروع |
