# نصب، حالت آفلاین و اعلان‌های باشگاه تنیس سام

## نصب روی دستگاه

| دستگاه | مسیر نصب |
| --- | --- |
| مک | نسخهٔ محلی را در Chrome یا Edge باز کنید و گزینهٔ نصب مرورگر را انتخاب کنید. در Safari 17 و macOS Sonoma به بعد، از File → Add to Dock استفاده کنید. |
| iPhone و iPad | نشانی HTTPS سامانه را در Safari باز کنید. از منوی اشتراک‌گذاری، Add to Home Screen را بزنید. برای اعلان دستگاه، برنامهٔ نصب‌شده را از صفحهٔ اصلی باز کنید. Web Push به iOS یا iPadOS 16.4 به بعد نیاز دارد. |
| Android | نشانی HTTPS را در Chrome باز کنید و از منوی مرورگر Install app یا Add to Home screen را بزنید. |

راهنمای نصب از صفحهٔ ورود و مرکز اعلان‌ها در دسترس است. manifest، آیکون‌های ۱۹۲ و ۵۱۲، آیکون maskable و آیکون ویژهٔ Apple در نسخهٔ محلی و نمونهٔ آنلاین مشترک‌اند. رنگ آغاز و نام برنامه از manifest می‌آید. [WebKit برای آیفون و آیپد](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/) · [WebKit برای مک](https://webkit.org/blog/14445/webkit-features-in-safari-17-0/)

### دسترسی از گوشی به نسخهٔ محلی روی مک

نصب پیش‌فرض روی `http://127.0.0.1:3030` است. این نشانی فقط روی خود مک قابل دسترسی است. برای گوشی، یک نشانی HTTPS در شبکهٔ باشگاه تنظیم کنید. مرورگر باید گواهی TLS آن را معتبر بداند. PostgreSQL و سرویس ورود روی شبکهٔ داخلی Docker می‌مانند. [Secure contexts و Service Worker](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API)

۱. برای مک در شبکهٔ باشگاه یک IP خصوصی پایدار در نظر بگیرید. در نمونهٔ زیر `192.168.1.50` را با IP واقعی مک و `3030` را با پورت محلی نصب خودتان عوض کنید. در `.local/secrets.env` فقط مقدار `SAM_ORIGIN` را به `https://192.168.1.50:8443` تغییر دهید و `./scripts/local.sh up` را اجرا کنید.

۲. این پیکربندی را برای Caddy نصب‌شده روی مک در `.local/Caddyfile` قرار دهید. برای اجرا، `caddy run --config .local/Caddyfile --adapter caddyfile` را در پوشهٔ پروژه بزنید. پورت ۸۴۴۳ روی IP خصوصی مک گوش می‌دهد. از انتقال این پورت در روتر به اینترنت خودداری کنید.

```caddy
{
    auto_https disable_redirects
}
https://192.168.1.50:8443 {
    bind 192.168.1.50
    tls internal
    reverse_proxy 127.0.0.1:3030
}
```

۳. فقط گواهی عمومی مرجع همین نصب (`pki/authorities/local/root.crt` در مسیر دادهٔ Caddy) را به دستگاه‌های تحت مدیریت خود منتقل کنید. مسیر داده را در خروجی `caddy environ` از `caddy.AppDataDir` بخوانید. در iOS، پس از نصب گواهی، آن را در Settings → General → About → Certificate Trust Settings برای SSL معتبر کنید. سپس همان نشانی HTTPS را روی مک و گوشی باز کنید و از Safari به صفحهٔ اصلی اضافه کنید. با تغییر نشانی، روی نشانی جدید دوباره وارد شوید. [TLS داخلی Caddy](https://caddyserver.com/docs/caddyfile/directives/tls) · [راهنمای اعتماد به گواهی Apple](https://support.apple.com/en-us/102390)

اگر Caddy را برای همین نصب با Homebrew راه انداخته‌اید، می‌توانید پیکربندی را در `$(brew --prefix)/etc/Caddyfile` بگذارید و با `brew services start caddy` آن را هنگام ورود به مک اجرا کنید. در این حالت از گواهی همان سرویس استفاده کنید. Homebrew مسیر دادهٔ سرویس را زیر `$(brew --prefix)/var/lib` قرار می‌دهد. [پیکربندی Caddy در Homebrew](https://formulae.brew.sh/formula/caddy)

## رفتار قطع اتصال و به‌روزرسانی

- Cache Storage فقط راهنمای عمومی آفلاین، manifest و چهار آیکون را نگه می‌دارد. HTML پنل، دادهٔ React Server Components، اعلان‌های مدیر، خروجی گزارش، درخواست‌های API و پاسخ ثبت مالی وارد آن نمی‌شوند.
- پس از نصب موفق Service Worker، قطع ارتباط یا خطای دروازهٔ سرور در ناوبری، راهنمای عمومی را نشان می‌دهد. کاربر نتیجهٔ عملیات قبلی را بعد از اتصال در رکورد اصلی می‌بیند. ثبت رزرو، دریافت، تسویه و تغییر وضعیت نیازمند تأیید سرور هستند. صف ارسال آفلاین برای عملیات باشگاه وجود ندارد.
- فایل‌های هش‌دار Next.js طبق سیاست immutable خود Next.js در Cache HTTP مرورگر می‌مانند. پاسخ‌های خصوصی `no-store` هستند. پس از آماده‌شدن Service Worker جدید، مدیر زمان بارگذاری مجدد را انتخاب می‌کند. نسخهٔ کش عمومی همراه تغییر فایل‌های کش‌شده افزایش می‌یابد.

## اعلان مدیران

مرکز اعلان‌ها برای مالک و مدیران شعبه فعال است. رخدادها با تراکنش تغییر منبع در PostgreSQL ثبت می‌شوند. علامت خوانده‌شدن برای هر مدیر جداگانه ذخیره می‌شود. این اعلان‌ها به مدیر می‌رسند و تغییرات مرتبط با مربی یا شاگرد از پنل مدیریت قابل پیگیری‌اند.

| رخداد | قاعده |
| --- | --- |
| یادآوری جلسه | از یک ساعت قبل تا شروع جلسهٔ برنامه‌ریزی‌شده. جابه‌جایی، لغو یا ثبت برگزاری، یادآوری قبلی را از گردش خارج می‌کند. |
| تغییر برنامه و فهرست کلاس | ثبت جابه‌جایی و لغو سانس، تغییر ساعت کاری مربی و تغییر ثبت‌نام کلاس گروهی آینده |
| پیگیری پرداخت | ۱۶۸ ساعت بعد از صدور فاکتور دارای مانده. پس از تسویه یا ابطال از مرکز اعلان خارج می‌شود. |
| هشدار برنامهٔ شعبه | ثبت تعطیلی یا تعمیرات مؤثر در برنامه |

### فعال‌کردن اختیاری Web Push

اعلان داخل پنل به تنظیم جدا نیاز ندارد. برای ارسال اعلان سیستم‌عامل، مالک روی رایانهٔ میزبان یک نشانی تماس معتبر برای VAPID تنظیم می‌کند.

```sh
./scripts/local.sh push-setup mailto:manager@example.com
```

پس از راه‌اندازی، در صفحهٔ «مرکز اعلان‌ها»، روی همان دستگاه «فعال کردن اعلان» را بزنید. لغو اشتراک از همان صفحه ممکن است. خروج از حساب، اشتراک همان مرورگر را در سرور حذف می‌کند. در آیفون، این مرحله از داخل برنامهٔ افزوده‌شده به صفحهٔ اصلی انجام می‌شود. برای ارسال دستگاه، رایانهٔ میزبان و سرویس اعلان مرورگر به اینترنت نیاز دارند. متن نمایشی روی صفحهٔ قفل عمومی است. جزئیات رزرو، شاگرد یا پرداخت از پنل محلی با ورود مدیر خوانده می‌شود. ارسال Email و SMS به سرویس متصل نیاز دارد و در این نصب تنظیم نشده است. [WebKit Web Push](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/)

`.local/push.env` شامل کلید اختصاصی نصب است. با فایل تنظیمات محلی محافظت و پشتیبان‌گیری شود. صف ارسال، دسترسی شعبه و فعال‌بودن عضویت را هنگام دریافت کار بررسی می‌کند. ثبت یکتای هر رویداد و دستگاه از ارسال دوبارهٔ عادی جلوگیری می‌کند. نتیجهٔ موقت تا پنج تلاش دوباره بررسی می‌شود و اشتراک منقضی حذف می‌شود. در فاصلهٔ پذیرش پیام از سوی سرویس مرورگر و ثبت نتیجه در دیتابیس، خرابی می‌تواند تکرار ایجاد کند. شناسهٔ ثابت پیام و اعلان به جلوگیری از نمایش دوبارهٔ همان اعلان کمک می‌کند.

## نتیجهٔ آزمون و عملکرد

- ساخت تولیدی و آزمون محلی PostgreSQL 17.11 و GoTrue انجام شد. آزمون HTTP نصب‌پذیری، پاسخ بدون کش دادهٔ خصوصی، محدودیت شعبه، جلوگیری از ثبت دوبارهٔ اعلان، اشتراک و لغو، و صف ارسال هم‌زمان را پوشش می‌دهد. ارسال به سرویس مرورگر با گیرندهٔ آزمایشی شبیه‌سازی شد.
- در Chrome روی پیش‌نمایش، سه نمای تقویم، گزارش و اعلان در ۳۲۰، ۳۷۵، ۳۹۰، ۷۶۸، ۱۰۲۴، ۱۴۴۰ و ۱۹۲۰ پیکسل بررسی شدند. سرریز افقی صفحه مشاهده نشد. دکمهٔ اصلی اعلان در نمای ۳۹۰ پیکسل ۴۴ پیکسل ارتفاع داشت. پس از توقف سرور، راهنمای آفلاین باز شد.
- پشتیبانی صفحه‌کلید، focus قابل مشاهده، برچسب فیلدها، وضعیت خوانده‌نشده با متن، safe area و کاهش حرکت در CSS و رابط بررسی شدند. ارزیابی دستگاه واقعی و صفحه‌خوان کامل در این محیط انجام نشد.

فهرست اعلان در سرور در صفحه‌های ۲۴ رکوردی خوانده می‌شود. خواندن‌ها و کارهای آمادهٔ ارسال ایندکس دارند. عکس اصلی و فونت‌های محلی WebP و WOFF2 باقی مانده‌اند. آزمون برنامهٔ کوئری تقویم روی ۲۴۰۰ ردیف تاریخی، زمان اجرای حدود ۲٫۱ میلی‌ثانیه ثبت کرد. صدک ۷۵ LCP، INP و CLS روی گوشی و شبکهٔ واقعی هنوز اندازه‌گیری نشده است. آزمون نصب و دریافت Push روی iPhone، iPad و Android فیزیکی هنگام راه‌اندازی روی دستگاه لازم است.
